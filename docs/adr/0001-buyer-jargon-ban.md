# Hide web3 jargon from the buyer

Event Pass purchase showed Smart account, Kernel, EntryPoint, UserOperation, Bundler, Counterfactual, Arbiscan, chain ID, and revenue recipient addresses, with repeated escrow/refund paragraphs and kernel lifecycle banners that bury the buyer's intent. We decided buyer-visible UI uses only Event Pass, USDC price, and Face ID/fingerprint cue; full payment recipient and refund details live in a single collapsed Details disclosure, and hashes/explorer links are hidden. Internals remain in diagnostics, not in the funnel.
