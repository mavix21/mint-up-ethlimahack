# Keep private resale separate from payment protection

An owner may offer an active Event Pass at any positive USDC price to one Mint Up user whose protected account is resolved from email offchain. Acceptance atomically sends 91% to the seller, 9% to Mint Up, and changes ownership; resale proceeds are immediate rather than retained, so a later cancellation returns only the original primary price to the current holder. This demonstrates safe exchange without adding a public marketplace or a second escrow ledger.
